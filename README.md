# 🧭 Хук `useWindowScroll`

Ветка: `feature/use-window-scroll`

Хук для отслеживания текущей позиции прокрутки окна и программного управления ею.

## Цель

Дать компонентам возможность реагировать на прокрутку страницы пользователем, а также предоставить удобный инструмент для программного скролла к нужным координатам с поддержкой плавной анимации.

## Решаемые проблемы

1.  **Отслеживание прокрутки:** Компоненты знают, на сколько пикселей прокручена страница, и могут менять своё поведение (например, показывать/скрывать кнопку "Наверх").
2.  **Программный скролл:** Упрощение навигации по странице, избавление от нативного `window.scrollTo` и ручного управления анимацией.
3.  **Согласованность состояния:** Хук гарантирует, что состояние `scroll` обновляется как при нативной прокрутке, так и при вызове `scrollTo`.
4.  **SSR-безопасность:** Корректная работа в средах серверного рендеринга.

## Использование

```tsx
import { useWindowScroll } from './hooks/useWindowScroll';

function ScrollApp() {
  const { scroll, scrollTo } = useWindowScroll();

  return (
    <div style={{ height: '200vh' }}>
      <p>Прокручено по вертикали: {scroll.y}px</p>
      <button onClick={() => scrollTo({ y: 0, behavior: 'smooth' })}>
        Плавно наверх!
      </button>
      <button onClick={() => scrollTo({ y: 500, behavior: 'auto' })}>
        Резко к 500px
      </button>
    </div>
  );
}
```

2.  **Запустите приложение:** `npm run dev`

4.  **Нажмите кнопку "Плавно наверх!"** для демонстрации программного скролла.
5.  **Попробуйте другие кнопки** для горизонтальной и комбинированной прокрутки.

## Важные детали

*   **Вспомогательный хук:** Использует внутренний хук `useWindowEvent` для безопасной подписки на событие `scroll` с автоматической отпиской.
*   **Поведение скролла:** Поддерживает опции `behavior: 'smooth' | 'auto'` для плавной или мгновенной прокрутки.
*   **Типизация:** Полная типобезопасность с чётко описанными типами `WindowScroll` и `ScrollOptions`.
*   **Инициализация:** На сервере возвращает `{ x: 0, y: 0 }`, на клиенте — актуальные значения прокрутки.
*   **Производительность:** Использует `useCallback` для мемоизации функций и избежания лишних ререндеров.
