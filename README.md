# ✨ Хук `useHover`

Ветка: `feature/use-hover`

Хук для отслеживания состояния наведения курсора на DOM-элемент.

## Цель

Предоставить декларативный способ реагировать на события наведения курсора мыши на любой элемент, что является частой задачей при создании интерактивных интерфейсов (подсказки, анимации, смена стилей).

## Решаемые проблемы

1.  **Упрощение логики:** Избавляет от необходимости вручную добавлять и удалять обработчики `mouseenter` и `mouseleave` с помощью `addEventListener`.
2.  **Декларативность:** Состояние наведения становится простым булевым значением, которое можно использовать в JSX.
3.  **Типобезопасность:** Хук типизирован с помощью дженерика, что позволяет указать конкретный тип элемента (например, `HTMLDivElement`), к которому применяется ref.
4.  **Автоматическая очистка:** Обработчики событий автоматически удаляются при размонтировании компонента.

## Использование

```tsx
import { useHover } from './hooks/useHover';

function MyComponent() {
  const { hovered, ref } = useHover<HTMLDivElement>();

  return (
    <div
      ref={ref}
      style={{
        background: hovered ? 'lightblue' : 'lightgray',
        padding: '20px',
        transition: 'background 0.3s',
        border: '2px solid darkblue',
        borderRadius: '8px'
      }}
    >
      {hovered ? '🎉 Курсор над элементом!' : 'Наведи на меня курсор'}
    </div>
  );
}
```
## Тестирование

1.  **Убедитесь, что вы находитесь в ветке `feature/use-hover`.**
2.  **Запустите приложение:** `npm run dev`
3.  **Наведите курсор на текстовый блок** и убедитесь, что его стиль и содержимое меняются.
4.  **Отведите курсор в сторону** - стиль должен вернуться к исходному состоянию.
5.  **Проверьте несколько раз** для подтверждения стабильной работы.

## Важные детали

*   **События `mouseenter`/`mouseleave`:** Используются вместо `mouseover`/`mouseout`, так как они не всплывают и более предсказуемо отслеживают наведение именно на целевой элемент, игнорируя его дочерние элементы.
*   **Generic-типы:** Поддерживает строгую типизацию через дженерик `<T extends HTMLElement>`.
*   **useRef с non-null assertion:** Использует `useRef<T>(null!)` для удобства, предполагая что ref будет обязательно присвоен элементу.
*   **useEffect с зависимостями:** Пустой массив зависимостей гарантирует, что обработчики добавляются только при монтировании.
*   **Стабильное API:** Возвращает объект с постоянной структурой `{ hovered, ref }`.
