# 🔄 Хук `useToggle`

Ветка: `feature/use-toggle`

Универсальный хук для переключения между двумя или более состояниями.

## Цель

Создать гибкий переключатель, который может работать как с простыми булевыми значениями (`true`/`false`), так и циклически перебирать массив произвольных значений (например, темы: `['light', 'dark', 'auto']`).

## Решаемые проблемы

1.  **Универсальность:** Замена множества отдельных `useState` для булевых флагов и перечислений одним унифицированным хуком.
2.  **Удобство API:** Простая функция `toggle()` для циклического переключения и возможность явной установки значения.
3.  **Продвинутая типизация:** Полная типобезопасность благодаря сложной системе дженериков, которая автоматически определяет типы переданных значений.
4.  **Производительность:** Использование `useReducer` для оптимального управления состоянием.

## Использование

**Булевый режим:**
```tsx
const [isOn, toggle] = useToggle(); // Начальное значение: false

toggle();       // true
toggle();       // false
toggle(true);   // Явно установит true
```
**Режим массива значений:**
```tsx
const themes = ['light', 'dark', 'auto'];
const [theme, toggleTheme] = useToggle(themes); // Начальное: 'light'

toggleTheme();          // 'dark'
toggleTheme();          // 'auto'
toggleTheme();          // 'light'
toggleTheme('dark');    // Явно установит 'dark'
```
**Практический пример:**

```tsx
function ThemeSwitcher() {
  const themes = ['light', 'dark', 'auto'];
  const [theme, toggleTheme] = useToggle(themes);

  return (
    <div>
      <p>Текущая тема: {theme}</p>
      <button onClick={() => toggleTheme()}>
        Сменить тему
      </button>
      <button onClick={() => toggleTheme('dark')}>
        Установить тёмную
      </button>
    </div>
  );
}
```
## Тестирование

1.  **Убедитесь, что вы находитесь в ветке `feature/use-toggle`.**
2.  **Запустите приложение:** `npm run dev`
3.  **Протестируйте булевый переключатель** - нажимайте кнопку для переключения между true/false.
4.  **Протестируйте переключатель режимов** - наблюдайте циклическое переключение между "Режим 1", "Режим 2", "Режим 3".
5.  **Проверьте явную установку значений** - используйте кнопки для установки конкретных режимов.

## Важные детали

*   **Перегрузка функций:** Хук имеет две сигнатуры для булевого режима и режима массива.
*   **Автоматическая типизация:** Хук самостоятельно определяет типы переданных значений через сложную систему дженериков, без необходимости в `as const`.
*   **useReducer:** Внутренняя реализация использует `useReducer` для сложной логики переключения.
*   **Начальное значение:** В булевом режиме - `false`. В режиме массива - первый элемент.
*   **Циклическое переключение:** В режиме массива переключатель зациклен - после последнего элемента возвращается к первому.
*   **Защита от невалидных значений:** При явной установке значения, не входящего в массив, состояние не изменяется.
*   **Readonly массивы:** Хук корректно работает как с обычными, так и с readonly массивами.
