# 💾 Хук `useLocalStorage`

Ветка: `feature/use-local-storage`

Хук для синхронизации состояния React-компонента с `localStorage`.

## Цель

Обеспечить простой и эффективный способ сохранения и восстановления состояния приложения между сессиями пользователя, делая работу с `localStorage` такой же простой, как и с обычным состоянием React.

## Решаемые проблемы

1.  **Синхронизация:** Автоматическая запись в `localStorage` при изменении состояния и чтение из него при инициализации компонента.
2.  **Упрощение API:** Предоставление простого интерфейса для работы с persistent storage.
3.  **Производительность:** Мемоизация функций для предотвращения лишних ререндеров дочерних компонентов.
4.  **Согласованность:** Гарантия того, что состояние в компоненте всегда соответствует данным в `localStorage`.

## Использование

```tsx
import { useLocalStorage } from './hooks/useLocalStorage';

function UserSettings() {
  const [username, { setItem: setUsername, removeItem: removeUsername }] =
    useLocalStorage('user-name');

  return (
    <div>
      <input
        value={username || ''}
        onChange={(e) => setUsername(e.target.value)}
        placeholder="Введите ваше имя"
      />
      <button onClick={removeUsername}>Очистить имя</button>
      <p>Привет, {username || 'гость'}!</p>
    </div>
  );
}
```
## Тестирование

1.  **Убедитесь, что вы находитесь в ветке `feature/use-local-storage`.**
2.  **Запустите приложение:** `npm run dev`
3.  **Введите текст в поле ввода** - значение автоматически сохранится в `localStorage`.
4.  **Обновите страницу** - убедитесь, что текст сохранился после перезагрузки.
5.  **Нажмите "Очистить имя"** - значение удалится из `localStorage` и состояния.
6.  **Проверьте в DevTools** вкладку Application → Local Storage чтобы увидеть изменения.

## Важные детали

*   **Только строки:** `localStorage` работает исключительно со строками. Хук ожидает строку для `setItem`.
*   **Мемоизация:** Функции `setItem` и `removeItem` стабильны и не изменяются при каждом рендере, если не изменился `key`.
*   **Null-safe:** Возвращает `null` если ключ отсутствует в `localStorage`.
*   **SSR-безопасность:** Корректно работает в средах серверного рендеринга.
*   **Простая типизация:** Использует строгую типизацию для ключей и значений.
*   **Автоматическая синхронизация:** Изменения через `setItem` сразу обновляют и состояние компонента, и `localStorage`.
