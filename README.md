# 🎣 Хук `useFetch`

Ветка: `feature/use-fetch`

Универсальный хук для выполнения HTTP-запросов в React-компонентах.

## Цель

Инкапсулировать всю сложную логику работы с сетевыми запросами (`fetch`, `AbortController`, обработка состояний загрузки и ошибок) в простой и типобезопасный хук, который можно переиспользовать.

## Решаемые проблемы

1.  **Избежание boilerplate-кода:** Больше не нужно вручную создавать `AbortController`, вызывать `fetch`, парсить JSON и обновлять состояние для каждого запроса.
2.  **Безопасность:** Автоматическая отмена предыдущих запросов при повторном вызове и при размонтировании компонента предотвращает утечки памяти и установку состояния в unmounted components.
3.  **Типобезопасность:** Полная типизация запроса и ответа через дженерик `<T>`. TypeScript будет знать структуру ваших данных `data`.
4.  **Производительность:** Интегрированная логика для избежания race conditions и оптимизация повторных запросов.

## Использование

```tsx
import { useFetch } from './hooks/useFetch';

interface User {
  id: number;
  name: string;
  email: string;
}

function UserList() {
  const { data, isLoading, error, refetch } = useFetch<User[]>('https://api.example.com/users');

  if (isLoading) return <div>Загрузка пользователей...</div>;
  if (error) return <div>Ошибка: {error}</div>;

  return (
    <div>
      <button onClick={() => refetch({ params: { page: 2 } })}>
        Загрузить 2 страницу
      </button>
      {data?.map(user => (
        <div key={user.id}>
          <h3>{user.name}</h3>
          <p>{user.email}</p>
        </div>
      ))}
    </div>
  );
}
```
**Пример с POST-запросом:**

```tsx
function CreateUser() {
  const { data, isLoading, error, refetch } = useFetch<User>('https://api.example.com/users', {
    method: 'POST',
    body: { name: 'John', email: 'john@example.com' }
  });

  const handleSubmit = () => {
    refetch({
      method: 'POST',
      body: { name: 'Jane', email: 'jane@example.com' }
    });
  };

  return (
    <div>
      <button onClick={handleSubmit} disabled={isLoading}>
        {isLoading ? 'Создание...' : 'Создать пользователя'}
      </button>
      {data && <div>Пользователь создан: {data.name}</div>}
      {error && <div>Ошибка: {error}</div>}
    </div>
  );
}
```
## Тестирование

1.  **Убедитесь, что вы находитесь в ветке `feature/use-fetch`.**
2.  **Запустите приложение:** `npm run dev`
3.  **Наблюдайте за процессом загрузки** - должен отобразиться индикатор загрузки.
4.  **Дождитесь успешной загрузки** - данные должны отобразиться на странице.
5.  **Протестируйте повторный запрос** - используйте кнопки для загрузки данных с разными параметрами.
6.  **Проверьте обработку ошибок** - можно временно изменить URL на несуществующий в коде компонента.

## Важные детали

*   **Автоматическая отмена:** При новом вызове `refetch` или при размонтировании компонента предыдущий запрос автоматически отменяется.
*   **Сериализация тела:** Для методов `POST` и `PUT` объект `body` автоматически сериализуется в JSON с проверкой на циклические ссылки.
*   **Query-параметры:** Объект `params` автоматически преобразуется в корректную query-строку URL.
*   **Пустые ответы:** Корректно обрабатывает ответы с пустым телом (возвращает `null`).
*   **Статус ошибок:** Автоматически проверяет HTTP-статус ответа и генерирует ошибку для статусов не из диапазона 200-299.
*   **Мемоизация:** Функции `fetchData` и `refetch` мемоизированы для предотвращения лишних ререндеров.
