# 📐 Хук `useViewportSize`

Ветка: `feature/use-viewport-size`

Хук для отслеживания текущих размеров окна браузера (viewport).

## Цель

Предоставить реактивный способ получать актуальные размеры области просмотра и реагировать на их изменения, что критически важно для создания адаптивных и отзывчивых интерфейсов.

## Решаемые проблемы

1.  **Реактивность:** Компоненты автоматически перерисовываются при изменении размеров окна.
2.  **SSR-безопасность:** Корректно работает в средах серверного рендеринга, не вызывая ошибок из-за отсутствия `window`.
3.  **Производительность:** Использует мемоизированный обработчик и функцию инициализации состояния для избежания лишних вычислений.
4.  **Упрощение логики:** Избавляет от необходимости вручную подписываться на события `resize` и управлять их жизненным циклом.

## Использование

```tsx
import { useViewportSize } from './hooks/useViewportSize';

function ResponsiveComponent() {
  const { width, height } = useViewportSize();

  return (
    <div>
      <p>Ширина окна: {width}px</p>
      <p>Высота окна: {height}px</p>
      {width < 768 && <p>У вас мобильное устройство!</p>}
      {width >= 768 && width < 1024 && <p>У вас планшет!</p>}
      {width >= 1024 && <p>У вас десктоп!</p>}
    </div>
  );
}
```
## Тестирование

1.  **Убедитесь, что вы находитесь в ветке `feature/use-viewport-size`.**
2.  **Запустите приложение:** `npm run dev`
3.  **Изменяйте размер окна браузера** - цифры на странице будут обновляться в реальном времени.
4.  **Протестируйте адаптивность** - убедитесь, что текстовые сообщения меняются при достижении брейкпоинтов.

## Важные детали

*   **Вспомогательный хук:** Использует внутренний хук `useWindowEvent` для безопасной подписки на событие `resize`.
*   **Инициализация:** На сервере возвращает `{ width: 0, height: 0 }`. На клиенте при первом рендере устанавливаются актуальные размеры окна.
*   **Производительность:** Обработчик события `resize` мемоизирован с помощью `useCallback`.
*   **Типизация:** Использует тип `ViewportSize` для строгой типизации возвращаемых значений.
*   **Автоочистка:** При размонтировании компонента автоматически отписывается от события `resize`.
